# コネクト・タイムトラベラー 〜90分でたどる日本のネット史とIT基礎〜

大学の90分授業「IT歴史・情報リテラシー」などでそのまま使える、1回完結型のワークショップ教材です（文系学生・留学生向け）。
1984年の JUNET から、常時接続のブロードバンド、現在のクラウド・AI まで、日本のインターネットの歴史を「自分でネットワークを組み立てる」体験でたどりながら、ITパスポート試験の学習にも役立つネットワーク・セキュリティの基本用語を **35枚の用語カード** として集めます。授業のあとは、同じファイルがスマホ向けの **単語帳・1分ドリル・就活カード** になります。

`connect_time_traveler/index.html` をブラウザで開くだけで動きます（パソコン・スマホ対応、サーバー不要、1ファイル完結）。

> GitHub のファイル表示や Claude アプリ内のプレビューでは、HTML はデザインなしの素の文字で表示されます。
> ファイルを保存（ダウンロード）して Chrome / Safari / Edge / Firefox で開いてください。

## ねらい

- 文系学生が抱きがちな「IT用語への苦手意識」を、**体験 → 名前を知る（用語カード） → たとえで理解する** の順でほぐす
- 1984年 → 1995〜2001年 → 現在 の3つの時代を通して、パケット・プロトコル・DNS・ベストエフォート・クラウド・TLS などが「なぜ必要になったのか」を歴史の流れで理解する
- 授業後もスマホで復習でき、ITパスポート試験の学習や就職活動の会話に使える形で残す

## 留学生への配慮

- 画面右上で **日本語／English／日本語+English（2段表示）** を切り替え（すべての画面・クイズ・用語カードが対応）
- **ふりがな**（メニューまたは Alt+F）：難しい漢字に読みを表示
- 用語カードには日本語・英語・読みを併記（英語表示でも日本語の用語を表示し、日本語で行われる試験に備えられる）
- 文字は読みやすさに配慮した BIZ UDPゴシック（ユニバーサルデザインフォント）

## 構成（90分の流れ）

| 区分 | 時間 | 画面 | 内容 | 主な用語カード |
|---|---|---|---|---|
| 導入 | 15分 | `#/opening` | 事前アンケート（IT用語への不安度・予想）、回線スピード体験（300bps の文字表示、写真1枚の転送時間を計算）、従量課金の電話代の体験、1984年へのタイムスリップ | bps |
| 第1章 1984年 | 17分 | `#/ch1` | **バケツリレーと電話代（JUNET）**：10KBの研究メモを東大へ。まとめて送ると雑音で届かない → パケットに分ける（分割数と時間のU字カーブ）→ ヘッダ（荷札）の仕分け → 中継ルートを選ぶ（UUCP のバケツリレー）→ 昼・夜の電話代と予算で本番 | パケット、ヘッダ、誤り検出、プロトコル、UUCP、ドメイン名、IPアドレス |
| 第2章 1995〜2001年 | 17分 | `#/ch2` | ダイヤルアップの接続順 → 23時の壁（テレホタイム）の混雑シミュレーション → ADSL か光か（局からの距離と予算のパズル）→ 家庭のLANとWAN → URLを入れると何が起きる？（DNS と WWW） | ISP、ダイヤルアップ、常時接続、ブロードバンド、ベストエフォート、ADSL、FTTH、ルーター、LAN、WAN、DNS、WWW、URL |
| 第3章 現在 | 16分 | `#/ch3` | 携帯の年表 → 壊れても届くネットワーク（災害テストつきの防衛戦）→ エンドツーエンドの考え方 → クラウドの仕分け（SaaS/PaaS/IaaS）→ カフェのWi-Fiで守る（盗み見の比較、安全な行動、多要素認証） | モバイル、ルーティング、冗長化、自律分散、エンドツーエンド、TCP/IP、クラウド、SaaS、PaaS、IaaS、暗号化、SSL/TLS、多要素認証、公衆無線LAN |
| 振り返り | 25分 | `#/quiz` `#/note` | **まとめクイズ**（10問・四肢択一 ア〜エ）→ 事後アンケート → **マイ復習ノート**（自分の結果・用語・クイズの解説を自動でまとめた図解ノート、印刷可）→ **学習コード**の提出 | — |

- 各章は「STEP 1 / 7」のような手順で進みます。課題をこなすと次へ進めます。まちがえると理由と手がかりが表示され、行き止まりにはなりません
- 補足の説明（歴史の詳細、技術の裏話など）は「もっと知りたい人へ」に折りたたんであり、授業時間内は本筋だけを進められます。早く終わった学生や復習のときに開けます
- 用語は体験した瞬間に **用語カード** として獲得します（画面上部のカウンターで、集めたカードをいつでも確認できます）
- ページを再読み込みしても、各章の続きのステップから再開します

## 授業のあと（スマホ）

`#/review`（下のタブで切り替え）

- **単語帳**：用語カードをめくって覚える（「覚えた／もう一度」、章ごとの絞り込み、スワイプ）
- **1分ドリル**：60秒の一問一答。前回まちがえた問題（まとめクイズでまちがえた問題を含む）から先に出題。ITパスポート試験の出題範囲を参考にした**オリジナル問題**30問と、まとめクイズの10問（クイズに答えたあとで出題）
- **就活カード**：「なぜ企業のメールは @会社名.co.jp なのか」「フリーWi-Fiで仕事をするときの注意」など9テーマ。面接や仕事で使える一言つき
- **マイ復習ノート**

### 学習コード（PC → スマホ、学生 → 教員）

サーバーを使わないため、記録は各端末のブラウザ（localStorage）にだけ保存されます。
その代わりに、復習ノートに表示される **学習コード**（例：`CT-2HGG4-00000-2G000-002CG`）で記録を受け渡します。

- **スマホへ引き継ぐ**：スマホで `#/sync`（ホームの「学習コードで続きから」）を開き、コードを入力。アプリを Web サーバー（GitHub Pages など）に置いた場合は、ノートの **QRコード** を読み取るだけで引き継げます
- **教員へ提出**：「提出用にコピー」した文字を LMS（Moodle・Google フォームなど）の提出欄に貼り付け
- コードに含まれるのは、各章の完了と★の数、獲得カード、まとめクイズの正誤、事前・事後の不安度だけです（氏名やメールアドレスは含みません）。打ち間違いはチェック用の値で検出します

## 教員メニュー（`#/teacher`）

- **授業進行タイマー**：90分の時間割（導入15・第1章17・第2章17・第3章16・振り返り25分）、残り時間、いま話すことのメモ、全画面表示。再読み込みしても続きから
- **教室対戦クイズ**：プロジェクター用のチーム対抗戦（2〜6チーム、制限時間つき）。学生は手やカードで答え、先生が正解チームを押して得点
- **理解度ダッシュボード**：LMS から書き出した「学籍番号＋学習コード」をまとめて貼り付けると、完了率、まとめクイズの平均点と分布、問題ごとの正答率（60%未満は「要フォロー」）、不安度の変化（授業前→後）、用語カードの獲得率、★の分布、学生一覧を集計。同じ学籍番号の再提出は新しいほうを使います。表のコピー（Excel にそのまま貼れる形式）と CSV 保存に対応。何も貼り付けていないときは架空の見本が表示され、「サンプルデータで試す」で操作を練習できます
- **授業ガイド**：ねらい、90分の進め方、準備チェックリスト、解答一覧、「注意したい誤解（正確さのための注記）」
- **教員モード**（右上のメニュー）：プロジェクターでの説明用に、各章のどのステップにもすぐ移動できます（オンの間は画面上部に「教員モード」と表示）

## 正確さについて

歴史の記述・数値・用語の定義は、一次資料（JPNIC、JPRS、WIDE、NTT、総務省、IETF の RFC、NIST、各社の発表資料など）で確認し、別の確認担当が独立に再確認したうえで、出典を画面の [n] から「出典と注記」（`#/sources`）で確認できるようにしています（確認日：2026年10月）。

もとの設計案から、次の点を事実に合わせて改めています。

| 設計案の記述 | アプリでの扱い |
|---|---|
| 1984年に「慶應義塾大学（日吉）の村井純研究員」 | 1984年の村井純は東京工業大学（現・東京科学大学）総合情報処理センターの助手。最初の接続は1984年9月の慶應—東工大（300bps のモデムとされる）、10月に東大が加わって JUNET が始まった |
| JUNET は深夜にまとめて通信 | UUCP には料金の安い時間帯だけ電話をかける設定があったが、JUNET は定期的に（30分〜1時間おき程度）接続していたとされる。第1章の題も「バケツリレーと電話代」に変更 |
| 「通信費10万円時代」 | つないだ時間だけ電話代がかかる「従量課金」の時代（市内通話3分10円＝1時間約200円）。月10万円は極端な例 |
| ブロードバンドで「一気に1万倍」 | 理論上の最大速度で 56kbps→100Mbps は約1,800倍、300bps→100Mbps は約33万倍（区間を明示） |
| JUNET で IP アドレス・ドメイン | JUNET は主に UUCP。ドメインは `.junet`（JUNET 内部の名前）→ 1986年に `.jp` が委任、1989年に `ac.jp`・`co.jp` などへ移行。本格的な IP 網は1988年発足の WIDE プロジェクト |
| 村井教授が提唱した自律分散・End-to-End 原理 | End-to-End の原理はソルツァー、リード、クラークの論文（1981年）。村井純はインターネットの性質を「自律・分散・協調」と表現している、として別に紹介 |
| ITパスポートの「過去問」 | すべて**オリジナル問題**（ITパスポート試験の出題範囲を参考に作成、実際の試験問題ではない）と明記 |
| 「.co.jp を使うと信頼できる企業だと証明される」 | co.jp は日本で登記した会社が原則1組織1つだけ登録できる（登録時に確認される）。会社やメールの信頼性そのものを保証するものではない |

- パズルの数値（雑音の間隔、ヘッダの大きさ、料金・予算、回線数、地区の距離と速度、地図の位置とコストなど）は**ゲーム上の設定**で、画面にもそう表示しています
- ITパスポート試験の試験時間・出題数・合格基準などは、教材作成時に IPA の公式サイトで確認できなかったため、授業ガイドでは「最新情報は IPA 公式サイトで確認」としています。授業前に [IPA ITパスポート試験](https://www3.jitec.ipa.go.jp/JitesCbt/) で確認してください

## ファイル

`index.html` 1ファイルに、デザイン（CSS）・本文・データ・画面制御（JavaScript）をすべて収めています。
別ファイルを読み込まないので、このファイル1つをコピーするだけでどの環境でも動きます。
QRコードの生成には [QR Code Generator for JavaScript](https://github.com/kazuhikoarase/qrcode-generator)（MIT ライセンス）を同梱しています。

## 授業での使い方の例

1. 授業前：学生のPCで `index.html` を開けるようにする（LMS に置く、または GitHub Pages などで公開）。教員は「授業進行タイマー」を全画面で表示
2. 導入（15分）：事前アンケートとスピード体験。教員は「つないでいる時間だけ電話代がかかる」時代の話
3. 第1〜3章（50分）：各自がパズルを進める。終わった学生は「もっと知りたい人へ」を読む。教員は各章の切りかわりで要点を確認（教員モードで任意のステップを映せます）
4. 振り返り（25分）：まとめクイズ（または教室対戦クイズ）→ マイ復習ノート → 学習コードを LMS に提出
5. 授業後：提出されたコードをダッシュボードに貼り付け、正答率の低い問題を次回の授業で補う

学習の記録はブラウザの localStorage にのみ保存され、メニューの「記録をすべて消す」で初期化できます（教員メニューのデータは残ります）。
フォントは Google Fonts から読み込みますが、オフラインでも端末のフォントで表示され、すべての機能が動きます。

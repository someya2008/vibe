初回の90分ガイドに続く、おすすめの10回です。第2〜8回は毎回1つの題材で完結。第9〜11回は、好きな題材を深める3回にすると、AIの操作が「問いを調べる道具」へ育っていきます。

各回の成果物は小さく。

アプリ1つまたは改善1つ＋比較表＋短い振り返り。発表は画面を見せ合う程度にし、順位を付けず、指示や検証の工夫を持ち寄ります。最後の3回も、前回の作品がなければ動作見本から参加できます。

第2〜8回の基本の進め方

毎回同じ操作の順にすると、IT操作にかかる負担を抑えられます。生成に時間がかかることを見込み、教員はその日の題材の予備アプリ・固定データ・検算用の答えを用意します。

0–5分 / 5分前回の操作を確認
5–15分 / 10分題材と予想
15–30分 / 15分AIに仕様を伝える
30–40分 / 10分HTMLを保存・実行
40–50分 / 10分手計算と境界値
50–70分 / 20分3条件を実験
70–80分 / 10分Excelで整理
80–90分 / 10分振り返り・共有・保存

各回の短い依頼文は、仕様を相談するための出発点です。AIとルールを確かめた後、「通信不要・外部依存なし・単独HTML全体・固定データ・入力検証・手計算用の欄」を指定して制作を依頼します。保存と実行には初回ガイドの手順を共通で使えます。

02 予約できる学食 予測を上手に伝える / SDGs 12
考える問い
予約があると仕込みを減らせるか。予約しても来ない人が増えると、どうなるか。
学生が決める
予約外のお客さんに備える追加の仕込み数。予約数、予約キャンセル数、予約外需要は、全方針で同じ10日分の表を使う。
AIの学び
「予約でロスを減らしたい」を、入力・需要・売れた数・利益のルールに分けて伝える。キャンセル分を二重計上しないよう説明を求める。
確かめる
予約10、来ない人2、予約外需要3なら、実際の需要は11。仕込み12なら販売11、廃棄1、不足0。費用は仕込んだ全食数にかける。
Excel・提出
追加仕込み3条件の利益・廃棄・不足を入力。合計と1日平均を求め、廃棄の棒グラフと提案2文を保存。
注意する仮定
予約すれば需要が増える、と決め付けない。キャンセル率や追加需要の値は仮定とし、予約方法の使いやすさは別の調査が必要。
03 リユースの損益分岐点 先に式を確かめる / SDGs 12
考える問い
使い捨てとリユースでは、何回使うと累積費用が逆転するか。
学生が決める
使用回数を変える。初回の貸出店とは別モデルとし、今回はカップ1個の購入費と毎回の洗浄費を追う。
AIの学び
「最初だけかかる費用」と「毎回かかる費用」を、コード生成前に式と表で確認する。
確かめる
仮にリユース購入300円・洗浄1回5円、使い捨て1回20円なら、累積費用は300＋5nと20n。20回で同額400円、21回では405円と420円。購入後の0回では300円と0円。
Excel・提出
0〜30回の表と2本の折れ線グラフ。交点と「費用の話として言えること」を2文で示す。
注意する仮定
金額の逆転点は、環境負荷の逆転点と同じではない。紛失、破損、洗浄水・エネルギーの評価範囲は別に考える。
04 修理ワークショップ 同じ需要で比較 / SDGs 8・12
考える問い
修理枠を増やすと、修理完了数と店の利益はどう変わるか。
学生が決める
1日あたりの修理枠8・10・12。初回で修理を選んだ人は、需要Bで調べるか、1件あたり作業時間が異なる拡張を1つだけ加える。
AIの学び
需要、料金、費用をそろえて比較するよう指示する。アプリを改善したら、前後で同じ入力の答えを確かめる。
確かめる
初回と同じモデルならQ10・D8で修理8件、空き2枠、不足0、利益2,800円。空き枠を廃棄物と表示していないか確認。
Excel・提出
Q別の利益と受付できた割合を算出。需要Aの合計100件なら、受付できた割合＝修理完了数÷100。表と改善指示1件を保存。
注意する仮定
すべて修理成功という仮定がある。実際の廃棄削減数とは一致しない。能力の異なるスタッフを一律の枠として扱う限界も考える。
05 エコ配達のまとめ便 指標を分けて見る / SDGs 11・13
考える問い
配達便をまとめると、費用・走行距離・待ち時間はどう変わるか。
学生が決める
1日1便・2便・4便。8時間営業を等間隔に区切り、各便は固定20kmの巡回経路とする。注文の到着時刻は全条件で共通の固定リスト。
AIの学び
円・km・時間を別の指標として表示させる。地図や経路探索を加えず、簡単なモデルに範囲を絞る。
確かめる
1日2便なら40km。待ち時間は「次の便の出発まで」とし、注文時刻と出発時刻から手計算で2件確認する。最終便以降の注文をどう扱うか先に決める。
Excel・提出
便数・費用・距離・平均待ち時間を並べ、距離と待ち時間を別のグラフにする。「待ち時間○時間以内」という制約を添えて提案。
注意する仮定
便の積載量に上限を付けない基礎モデル。距離を減らしただけでCO2削減量を断定しない。積載量や再配達は発展課題にする。
06 商店の省エネ投資 単位・桁を点検 / SDGs 7・13
考える問い
設備を買い替える費用は、電気代の節約で何か月かけて回収できるか。
学生が決める
従来設備を続けるか、省エネ設備に替えるか。明るさなど必要なサービスは同じとし、使用時間を短くする実験とは区別する。
AIの学び
WとkW、日と月、初期費用と毎月の費用を区別して指示する。AIの単位換算を電卓で検証する。
確かめる
仮に100Wを1日10時間・30日使うなら30kWh/月。1kWh30円なら900円/月。料金や設備価格は実際の相場として扱わず、仮の値とする。
Excel・提出
月数と累積費用の表を作り、2本の折れ線で比較。回収時期と、使用時間を変えたときの違いを1文で説明。
注意する仮定
寿命、故障、工事費、割引率、季節変動は基礎モデルでは省略。CO2を扱う場合は排出係数の公表元・年度・単位も確認する。
07 フェアトレードカフェ 事実と仮説を分ける / SDGs 8・12
考える問い
仕入れ先へ多く支払う方針は、店の利益とどう両立するか。
学生が決める
仕入れ単価の異なる3方針を比較。まず販売価格・需要は固定する。次に需要が低い・中程度・高い場合で試す。
AIの学び
「倫理的な商品だから必ず売れる」という自動的な因果関係を入れず、需要の変化は別の仮説として指示する。
確かめる
1杯500円、豆などの変動費200円なら、100杯の粗利益は30,000円。仕入れ単価の変更でどの費用が変わるかを1つずつ確認。
Excel・提出
仕入れ3方針の粗利益と仕入支払額を整理。需要の増減率を変えた表を作り、「この需要なら継続できる」という条件付き提案を書く。
注意する仮定
仕入先への支払額は、生産者の手取り額と同じではない。ラベルや価格だけで労働条件の改善を証明しない。社会的効果を測るには別の資料が必要。
08 だれもが買える移動販売 評価基準を決める / SDGs 10・11
考える問い
人が多い地区へ集める方針と、小さな地区にも届ける方針をどう比べるか。
学生が決める
3地区への訪問回数の配分。1週間の総訪問回数を6回に固定し、各地区の需要・1回の対応上限・移動費を共通データにする。
AIの学び
利益の最大化だけでなく「各地区を週1回以上訪問」などの制約を日本語で指定する。重み付き総合点の恣意性も考える。
確かめる
訪問回数の合計が6、地区別対応数が需要と訪問回数×対応上限を超えない。需要0の地区の対応率は、0で割らず「対象外」とする。
Excel・提出
地区別の対応率＝対応数÷需要と、3地区の最小対応率を求める。利益と最小対応率を並べ、重視する基準を添える。
注意する仮定
週需要はまとめて数え、曜日の希望や乗降のしやすさを省略している。公平さを1つの数値で完全に表すことはできない。
09 探究① 問いを絞る 実験計画をAIと相談
考える問い
「もっと良くしたい」を、1回の実験で確かめられる問いにできるか。
90分の配分
見本を体験10分 → 問い・仮説15分 → AIと仕様相談15分 → 改善依頼・動作15分 → 検算10分 → 3条件比較15分 → 記録・振り返り10分。
学生が決める
題材1つ、変える変数1つ、固定する条件、比べる3条件。例：「カップのレンタル代が高いと、用意する数の提案は変わるか」。
AIの学び
AIに候補を出させ、自分で問いを選ぶ。いきなり大きなアプリにせず、既存アプリへの改善を1つに絞る。
Excel・提出
「問い／予想／変えるもの／固定するもの／測るもの／3条件」の実験計画1枚＋予備実験3行。前回作品がなければカップ見本でQ8・10・12を比較。
学術的な視点
主張の前に操作の定義を置く。比較相手をそろえる。予想に合わなかった結果も記録する。
10 探究② 仮定を揺らす 感度分析と反例
考える問い
需要や費用の仮定が違っても、同じ提案がよいと言えるか。
90分の配分
基準モデル確認10分 → 変える仮定を選ぶ10分 → AIに比較仕様を依頼15分 → 動作・検算15分 → 3×3条件の実験20分 → Excel10分 → 限界と振り返り10分。
学生が決める
方針3つ×仮定3つ。例：カップQ8・10・12を、1個のレンタル代30・50・70円で比べる。需要Aとその他の費用を固定する。
AIの学び
提案が逆転する条件を探すよう依頼する。逆転がなければ、その範囲を記録し、無理に劇的な結果を作らない。
確かめる
費用の増加分＝追加単価×Q×10日が、利益の減少分と一致するか。基準条件50円の結果が初回と一致するか。
Excel・提出
利益を3×3の表にし、条件別に最良の方針をマーク。「この範囲では／この条件になると」という結論2文。
前回なしでも
動作見本のカップを基準に、レンタル代の選択欄だけをAIに加えてもらう。変更前のファイルも保存して照合する。
11 探究③ 根拠を添えて提案 出典確認・短い報告
考える問い
モデルの結果を、だれに、どの範囲で提案できるか。
90分の配分
見本・結果確認10分 → 使うデータ1件を選ぶ10分 → 公表元を確認20分 → 仮の値との違いを整理15分 → 表・グラフ15分 → 文章推敲10分 → 画面共有・保存10分。
学生がする
自治体、政府統計、公的機関、事業者の公開資料などから、仮定に関係するデータを1件探す。原資料で公表元・年月・対象地域・単位・数値を確認する。見つからない値は仮定のまま残す。
AIの学び
自分で確かめた抜粋・数値だけを渡し、分かることと分からないことを整理させる。AIが出したURLや引用も、実際に原資料を開いて確認する。
Excel・提出
「問い／方法／結果（表かグラフ1つ）／提案／限界／出典」の1枚。数値を現実の値に替えた場合は再計算し、以前の結果と区別する。
共有の方法
PC画面で2人が互いに2分ずつ見る。「説明が分かった点」と「もう1つ確かめたい点」を1つずつ伝える。競争や大がかりなプレゼンは行わない。
前回なしでも
カップ見本の需要Aで3条件を実行してから開始する。関連データが見つからない場合も、必要なデータと限界を示して条件付き提案を完成させる。

ゲーム体験から、大学の学びへ進むために

  1. 実行前に予想を書く。数値がどう変わると思うか、理由も1文添える。
  2. 条件をそろえ、変数を1つずつ変える。同じ需要・同じ費用で比較した範囲を記す。
  3. 小さな手計算と境界値で確かめる。ゼロ、上限、赤字、合計の一致を確認する。
  4. 逆の結果と、うまくいかない条件も調べる。1回の結果を一般化せず、需要や費用を変えてみる。
  5. モデルと現実の距離を書く。省いたこと、仮の数値、現実で確かめるデータを明示する。

評価は、アプリの豪華さよりも「AIに具体的に指示できたか」「比較条件と計算を確かめたか」「根拠と限界を説明できたか」を重視します。ペアでも、各自が1文の予想と振り返りを残すと学びを確認できます。

授業案は2026年10月21日作成。第2〜11回も各90分。題材の数値は学習用の仮定です。実在の経営・環境効果を保証しません。初回ガイドと合わせて使えます。

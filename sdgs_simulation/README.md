# AIでつくる SDGsビジネス実験室

IT操作が得意でない大学生向けに、生成AIへの指示でSDGsビジネスシミュレーションを制作し、計算を確認して比較する教材です。初回は90分で完結します。コードの直接編集は不要です。

## ファイルと開き方

| ファイル | 用途 |
| --- | --- |
| `index.html` | 学生向け90分ガイド。題材選択、制作・修正プロンプトのコピー、生成HTMLの保存と実行、検算、比較表、振り返りの保存 |
| `sample.html` | 同じ仕様の動作見本。カップ貸出・スープ屋台・修理の3題材、固定需要A/B、3方針比較、1日検算 |
| `next-10.html` | 残り10回（第2〜11回）の授業案。各90分。第2〜8回は題材ごとに完結、第9〜11回は探究を深める構成 |

リポジトリをダウンロード・展開し、`sdgs_simulation/index.html` をPCのブラウザで開きます。インストール・ビルド・APIキーは不要です。生成AIを使う段階には通信と、授業で利用できるAIサービスが必要です。

スマートフォンへは、教員がこのフォルダを静的Webサーバーへ配置し、`sdgs_simulation/index.html` のURLを配布すると使いやすくなります。GitHubのblob画面では実行できません。スマホの保存HTMLのプレビューではJavaScriptが動かない場合があるため、ガイド内の実行画面、教員の公開URL、またはPCを使います。

各HTMLはCSS・JavaScriptを内包しています。相互リンクを使うにはこのフォルダのHTMLを一緒に置きます。参考教材へのリンク `../foodloss/simple.html` はリポジトリ内の相対パスです。初回ガイドのみ単独配布した場合は、参考教材を別途案内してください。

## 90分の流れ

| 時間 | 学習活動 |
| --- | --- |
| 0〜10分 | `foodloss/simple.html` を体験。利益・廃棄・品切れを見る |
| 10〜20分 | 3題材から選び、変えるものと予想を決める |
| 20〜35分 | 題材別の完成プロンプトを生成AIへ送る |
| 35〜45分 | HTMLをガイドに貼り付けて実行し、作品ファイルを保存 |
| 45〜55分 | 手計算、ゼロ、入力値、日別合計を確認 |
| 55〜75分 | 固定需要AでQ＝8・10・12を比較し記録 |
| 75〜85分 | 変化の理由、仮定、結論の範囲を考える |
| 85〜90分 | 短い振り返りと提出。HTML＋TXTを保存 |

45分時点で制作が終わらない場合は、動作見本の同じ題材で実験へ進みます。生成AIの出力は一律に成功するとは限らないため、担当教員は利用サービスとファイル保存を授業前に確認します。作品共有は順位を競う形式ではなく、画面を見せ合い工夫を確かめる活動を想定しています。

## モデル・検算

需要A＝`8,12,10,7,11,9,13,8,12,10`（合計100）、需要B＝`12,10,14,9,13,11,8,15,10,12`（合計114）。毎日の対応数S＝min(Q,D)、余りU＝Q−S、不足L＝D−S、利益＝P×S−V×S−F×Q。乱数を使わず、同じ需要で条件を比較します。

| 題材 | P（対応1件の収入） | V（対応1件の費用） | F（用意1単位の1日費用） | 社会・環境の指標 |
| --- | ---: | ---: | ---: | --- |
| カップ貸出 | 150円 | 30円 | 50円 | 対応数＝使い捨て使用回避数（想定） |
| スープ屋台 | 500円 | 0円 | 300円 | 余り＝廃棄した食数 |
| 修理 | 1,500円 | 400円 | 600円 | 対応数＝修理完了数（試算） |

Q10・D8の利益はそれぞれ460円・1,000円・2,800円。Q0・D8では全題材で利益0円、対応0、余り0、不足8。Q10・D0では利益がそれぞれ−500円・−3,000円・−6,000円になります。

需要Aでのカップ貸出の10日合計：

| Q | 利益 | 使用回避（想定） | 余り | 不足 |
| --- | ---: | ---: | ---: | ---: |
| 8 | 5,480円 | 79回 | 1個 | 21件 |
| 10 | 6,040円 | 92回 | 8個 | 8件 |
| 12 | 5,880円 | 99回 | 21個 | 1件 |

ここで「余り」は各日の未使用分の合計です。カップと修理の余りは廃棄物ではありません。需要・費用・金額はすべて学習用の仮定です。CO2削減量や実際の社会的効果は算定しません。短い固定データの結果を現実の最適解と断定しない構成です。

## ガイドのデータとHTML実行

- 進捗、選択題材、比較表、予想・振り返りを、このブラウザのlocalStorageへ保存します。個人情報は求めません。保存できない環境では画面に案内を出し、TXT保存で持ち帰れます。
- 生成HTMLは自動保存しません。HTMLを貼り付けるかファイルから読み込み、保存ボタンで作品HTMLを取得します。生成したHTMLファイル自体は書き換えずに保存します。
- 実行には `sandbox="allow-scripts"` のiframeを使い、同一オリジン権限・上位画面への遷移権限を与えません。実行用コピーには先頭のCSPで外部通信・外部資源・フォーム送信等の制限を追加します。単独HTMLの基本操作を想定しています。
- 記録の確認ボタンは、学生が入力した合計を、選んだ題材・需要Aの計算結果と照合します。アプリ全体の正しさを保証する機能ではなく、検算・境界値テストと併用します。
- コピーが使えない環境では、文章を選択して手動コピーできます。

# コンピュータ概論Ⅰ ふりかえりラボ

コンピュータ概論Ⅱ 第1回「前期（コンピュータ概論Ⅰ）のまとめ」用の、自主学習型の復習教材です。
`computer_review/index.html` をブラウザで開くだけで動きます（パソコン・スマホ対応、サーバー不要、1ファイル完結）。

> GitHub のファイル表示や Claude アプリ内のプレビューでは、HTML はデザインなしの素の文字で表示されます。
> ファイルを保存（ダウンロード）して Chrome / Safari / Edge / Firefox で開いてください。

## ねらい

- 前期の6分野を、**アニメーション・図・体験コーナー**で「動かしながら」思い出す
- 各章末の**確認クイズ**と、6分野横断の**総合テスト**で理解を確かめる
- 進みぐあい・最高得点・実績（バッジ）をブラウザに保存し、自分のペースで進められる

## 構成

| 章 | 内容 | 体験コーナー |
|---|---|---|
| 1. コンピュータ（ハードウェア） | 五大装置、CPU、記憶階層、補助記憶、入出力とインタフェース | 五大装置のデータの流れ（3+5 の計算を1ステップずつ）、クロック周波数のレース、記憶装置の速さ比較（レジスタを1秒とすると…）、装置の仕分けゲーム |
| 2. デジタルデータの表し方 | ビットとバイト、基数変換、単位、2の補数、文字コード、画像、音 | 8個のスイッチで2進数（2の補数モードあり）、基数変換の手順アニメ、単位換算、文字→UTF-8バイト列、RGB と解像度・色深度、標本化・量子化の波形と実際の音 |
| 3. ファイルとディレクトリ | 階層構造、絶対パス・相対パス、拡張子、圧縮・バックアップ・アクセス権 | ディレクトリの木を移動してパスを答える（ランダム出題）、拡張子マッチング |
| 4. OS とアプリケーション | ソフトウェアの層、OS の役割、OS の種類と UI、ライセンス | 層の積み木、マルチタスクのタイムスライス（1コア／2コア）、OS マッチング |
| 5. 表計算ソフト | セルと数式、関数、相対参照と絶対参照、グラフ | 本物のように動くミニ表計算（SUM・AVERAGE・IF など、課題つき）、数式コピーで参照がずれる体験（$ の効果）、目的に合うグラフ選び |
| 6. データベース | DBMS、主キーと外部キー、正規化、関係演算と SQL、トランザクションと排他制御 | 主キーになれる列さがし、正規化していない表の更新異常、SQL（SELECT / WHERE / JOIN / ORDER BY）の実行、ロックあり／なしの同時予約 |

- 確認クイズ：各章 6〜8 問（4択、解説つき、選択肢はシャッフル）
- 総合テスト：6章から均等に 18 問（`FINAL_N` で変更可）
- キーボード操作：A〜D または 1〜4 で回答、Enter で次へ

## ファイル

`index.html` 1ファイルに、デザイン（CSS）・本文・クイズ・体験コーナー・画面制御（JavaScript）をすべて収めています。
別ファイルを読み込まないので、このファイル1つをコピーするだけでどの環境でも動きます。

編集するときは `index.html` 内の次の場所を探してください。

| 場所 | 内容 |
|---|---|
| `<style>` | デザイン（ライト／ダークテーマ対応） |
| `const CHAPTERS = [` | 各章の本文・図（SVG）・体験コーナーの指定 |
| `const QUIZ = {` | クイズ問題（各問の `a[0]` が正解。問題の追加・修正はここ） |
| `const WIDGETS = {}` 以降 | 体験コーナーの動き（ミニ表計算エンジン、簡易 SQL などを含む） |
| `app.js ──` と書かれたコメント以降 | 画面切り替え・進捗の保存（localStorage）・クイズエンジン・バッジ |
| `const FINAL_N` | 総合テストの出題数 |

## 授業での使い方の例

1. 導入（5分）：ホーム画面を映し、6分野の全体像を確認
2. 自主学習（40分）：各自が気になる章から。体験コーナーを操作させ、章末クイズで 80% 以上を目標に
3. まとめ（15分）：総合テストに挑戦し、結果画面の「ふりかえり」で弱い章を確認 → その章へのリンクで復習

学習の記録はブラウザの localStorage にのみ保存され、ホーム画面の「記録をすべて消す」で初期化できます。
フォントは Google Fonts から読み込みますが、オフラインでも端末のフォントで表示され、すべての機能が動きます。

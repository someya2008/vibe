# vibe

授業・展示用に作ったアプリを、フォルダごとに置いています。

## 共通トップページ

ルートの [`index.html`](index.html) が、5つの授業用HTML教材を選ぶ共通メニューです。
内容・学べること・難しさ・時間の目安を表示します。教材は同じタブで開き、ブラウザの「戻る」で一覧へ戻れます。
難しさと時間は授業計画用の目安であり、測定値ではありません。

- **PCで使う**：リポジトリ全体をダウンロード・展開し、ルートの `index.html` をブラウザで開きます。GitHub上でHTMLのファイル表示を開いても、教材は実行されません。
- **Webで公開する**：さくらインターネットなどの公開フォルダに、ルートの `index.html` と `foodloss/`、`foodloss_q/`、`refrigerator/`、`computer_review/` を同じ階層で配置します。音楽などの教材内のファイルもフォルダごと転送してください。公開先のURLをPC・スマートフォンで開きます。
- **追加設定**：トップページにAPIキー・有料サービス・ビルド・外部ライブラリは不要です。リンクは相対パスなので、サブフォルダへの公開にも対応します。
- **React教材**：`todo/` はこのメニューの起動対象に含めていません。下記のMyTodoの手順で起動してください。

教材の機能は変更していません。一部の教材の外部フォントや学習データ・出典については、各教材の説明を参照してください。


| フォルダ | アプリ | 動かし方 |
|---|---|---|
| `foodloss/` | 品切れか廃棄か（食品ロス教材） | HTML をブラウザで開くだけ |
| `foodloss_q/` | もったいないクイズ（フードロス50問クイズ） | HTML をブラウザで開くだけ |
| `todo/` | MyTodo（個人用 Todo 管理） | `cd todo && npm install && npm run dev` |
| `refrigerator/` | 冷蔵庫エージェント・シミュレーション（食品ロス教材） | HTML をブラウザで開くだけ |
| `computer_review/` | コンピュータ概論Ⅰ ふりかえりラボ（前期のまとめ・復習教材） | HTML をブラウザで開くだけ |

# 品切れか廃棄か

新聞売り子問題（需要の不確実性と最適発注量）で食品ロスを考える教材アプリ。
高校生から一般向け。大学祭などの展示用。

## 使い方

`foodloss/index.html`（くわしい版）または `foodloss/simple.html`（かんたん版）を
ブラウザで開くだけで動きます（パソコン・スマホ対応）。
サーバーやビルドは不要です。フォントは Google Fonts から読み込みますが、
オフラインでも端末のフォントで表示され、計算やグラフはそのまま動きます。

## 内容

### かんたん版（simple.html）
中学生でも分かるように、操作は「仕入れる数」だけ。10日間お店を開け、捨てた数・
買えなかった人・もうけを、ほかの3つのお店（ひかえめ・ちょうどいい・品切れさせない）と比べる。

### くわしい版（index.html）

- **店長ゲーム**: 14日間、コンビニの弁当の仕入れ数を決め、利益と廃棄を体験する。オートモードあり
- **実験**: 発注量・需要予測のブレ・値引きを動かし、4000日分の平均で利益・廃棄・品切れ率を見る
- **理由**: 臨界比による解説
- **予測**: 予測精度と廃棄量の関係
- **考える**: 問いと、モデルの仮定・出典

# もったいないクイズ（フードロス50問クイズ）

フードロス（食品ロス）への関心を高める4択クイズアプリ（`foodloss_q/`）。
中学生から一般向け。授業の導入・まとめや、展示での体験用。

## 使い方

`foodloss_q/index.html` をブラウザで開くだけで動きます（パソコン・スマホ対応）。
サーバーやビルドは不要です。効果音はブラウザの Web Audio で合成しています。
BGM は `foodloss_q/bgm/` の mp3（Suno Pro プランで制作した2曲）を再生し、
読み込めない場合は合成 BGM に自動で切りかわります。画面右上のボタンで効果音と音楽をそれぞれ ON/OFF できます。

## 内容

- **50問・3段階の難易度**: やさしい（用語・家庭でできること）／ふつう（数字・制度・世界の状況）／むずかしい（商慣習・目標値・国際的な定義）
- **ランダム出題**: 1回 10問・20問・全50問から選択。50問を使い切るまで同じ問題は出ません。選択肢の順番も毎回シャッフル
- **解説と出典**: 正解・不正解のあと、理由がわかる解説と出典（農林水産省・消費者庁・環境省・FAO・UNEP など）を表示
- **ゲーミフィケーション**: 難易度別の得点、連続正解コンボで最大2倍、称号（フードロス博士など）、バッジ、ベストスコア保存、紙吹雪・効果音・BGM
- **BGM 2曲**: 「ウクレレ」（明るく軽快、授業向き）と「カフェジャズ」（落ち着いた雰囲気、展示向き）。タイトル画面のほか、右上の音楽ボタンのメニューからクイズの途中でもいつでも切りかえられる（クロスフェード）。「おまかせ」ではラウンドごとにランダムに切りかわる
- **ふりかえり**: 結果画面でまちがえた問題と正解を一覧表示
- キーボード操作: A〜D または 1〜4 で回答、Enter で次へ

## 音が出ないとき

- **音楽ボタンの表示を確認**: 右上のボタンが「🔇 音楽 OFF」なら、押してメニューから曲を選んでください。選んだ瞬間に曲が鳴ります（設定は保存されます）。
- **`bgm/` フォルダごと置く**: `index.html` だけをコピーすると mp3 が見つからず、合成音楽で代用します（その旨を画面下に表示します）。`foodloss_q/` フォルダごとコピーしてください。
- **自動再生のブロック**: ブラウザが再生を止めた場合は画面下に案内を出し、次のタップで再生します。
- **iPhone/iPad**: 本体横のマナースイッチ（消音）が入っていると音が出ません。音量ボタンも確認してください。
- **アプリ内のプレビュー**: GitHub や Claude などアプリ内のファイル表示では音や mp3 の読み込みが制限されることがあります。ファイルを保存して Chrome / Safari / Edge で直接開いてください。

数値は 2023年度推計（食品ロス量 464万トン）など、作成時点の最新の公表値を使っています。
更新があれば `index.html` 内の `QUESTIONS` 配列を直してください。

# MyTodo

React + TypeScript + Vite + Tailwind CSS + Zustand で作った、個人用の Todo 管理アプリ（`todo/`）。
タスクの作成・編集・削除、優先度・締め切り・カテゴリ、フィルタと検索、ドラッグ&ドロップの並び替え、
ダークモード、JSON エクスポート、LocalStorage による保存に対応しています。

```
cd todo
npm install
npm run dev
```

# 冷蔵庫エージェント・シミュレーション

家庭の食品ロス（食べ残し・直接廃棄・過剰除去）が、買い物の間隔・まとめ買い・冷蔵庫の奥の見えにくさ・
家族人数という行動だけからどう生まれるかを体験する、エージェントベースモデルの教材アプリ（`refrigerator/`）。
中学生から大学生・一般向け。`refrigerator/index.html` をブラウザで開くだけで動きます。
くわしくは `refrigerator/README.md` を参照。

# 品切れか廃棄か

新聞売り子問題（需要の不確実性と最適発注量）で食品ロスを考える教材アプリ。
高校生から一般向け。大学祭などの展示用。

## 使い方

`foodloss/index.html`（くわしい版）または `foodloss/simple.html`（かんたん版）を
ブラウザで開くだけで動きます（パソコン・スマホ対応）。
サーバーやビルドは不要です。フォントは Google Fonts から読み込みますが、
オフラインでも端末のフォントで表示され、計算やグラフはそのまま動きます。

## 内容

### かんたん版（simple.html）
中学生でも分かるように、操作は「仕入れる数」だけ。10日間お店を開け、捨てた数・
買えなかった人・もうけを、ほかの3つのお店（ひかえめ・ちょうどいい・品切れさせない）と比べる。

### くわしい版（index.html）

- **店長ゲーム**: 14日間、コンビニの弁当の仕入れ数を決め、利益と廃棄を体験する。オートモードあり
- **実験**: 発注量・需要予測のブレ・値引きを動かし、4000日分の平均で利益・廃棄・品切れ率を見る
- **理由**: 臨界比による解説
- **予測**: 予測精度と廃棄量の関係
- **考える**: 問いと、モデルの仮定・出典

# MyTodo

React + TypeScript + Vite + Tailwind CSS + Zustand で作った、個人用の Todo 管理アプリ（`todo/`）。
タスクの作成・編集・削除、優先度・締め切り・カテゴリ、フィルタと検索、ドラッグ&ドロップの並び替え、
ダークモード、JSON エクスポート、LocalStorage による保存に対応しています。

```
cd todo
npm install
npm run dev
```

# 冷蔵庫エージェント・シミュレーション

家庭の食品ロス（食べ残し・直接廃棄・過剰除去）が、買い物の間隔・まとめ買い・冷蔵庫の奥の見えにくさ・
家族人数という行動だけからどう生まれるかを体験する、エージェントベースモデルの教材アプリ（`refrigerator/`）。
中学生から大学生・一般向け。`refrigerator/index.html` をブラウザで開くだけで動きます。
くわしくは `refrigerator/README.md` を参照。

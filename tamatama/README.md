# 確率実験室『たまたま？』

予想と実験結果の違いを手掛かりに、確率を考える教材アプリ（`tamatama/index.html`）。
中学2年「確率」・高校数学A「場合の数と確率」向け。ブラウザで開くだけで動きます（パソコン・スマホ対応、ダークモード対応）。
単一の HTML ファイルで、外部ライブラリは使っていません。フォントのみ Google Fonts を読み込みますが、オフラインでも端末のフォントで動作します。

## 内容

### ステージ1：公平なコインを投げる（5ステップ）
1. **予想する** — 「10回投げたら表は何回？」を 0〜10 から選び、理由を書く
2. **10回投げる** — コインが1枚ずつ裏返るアニメーション。表の回数・割合・予想との差を表示
3. **もう10回、比べる** — 実験を重ねると「10回中の表の回数」のヒストグラムが積み上がる。「クラス全員分（40人×10回）」ボタンで一気に増やせる。理論の期待回数（二項分布 ₁₀Cₖ/1024）を重ねて比較
4. **100回・1,000回** — 投げるたびの「表の割合」の推移を折れ線で描き、同じ回数で最大4本重ねられる（10 / 100 / 1,000 / 10,000 回）。理論のめやす（1/2 ± 2σ の帯）を表示可能。表で数値も見られる
5. **表が続いたら？** — 「表が5回続いた。次は？」を3択で答えて理由を書き、200,000回のシミュレーションから「直前5回が表」だった場面だけを抜き出して次の1回を集計。ほぼ半々になることと、ゆれの目安（±2σ）を示す

### ステージ2：サイコロ2個の合計（3ステップ）
1. **予想する** — 「合計2と合計7は同じくらい出るか」を3択
2. **振って数える** — 1回振るアニメーション、36 / 360 / 3,600 回のまとめ振り。合計2〜12 の回数のヒストグラム（理論の期待回数を重ねられる）
3. **36通りの表で説明** — 6×6 の組合せ表。合計を選ぶとその合計になるマスが光り、組合せの数・理論の確率・実験での割合を並べて表示。グラフの棒をクリックしても表と連動

### 主張チェック（定着・次回の授業用）
「100回投げれば必ず50回表になる」「表が5回続いたから次は裏が有利」など6つの主張について、妥当／妥当でないを選び理由を書いてから答え合わせ。解説には根拠となる数値（₁₀₀C₅₀/2¹⁰⁰ ≈ 8.0%、P(7回以上)=176/1024 ≈ 17.2% など）を示し、該当する実験ステップへのリンクを付けています。

### 理論メモ
二項分布の表（n=10）、割合の標準偏差 σ=√(1/(4n)) の表、独立と「ギャンブラーの誤謬」、サイコロ2個の36通りの表、「たまたま」を疑う目安（ずれを σ と比べる）。

## 先生向け
- 右上の **「先生」スイッチ** で先生モード：すべてのステップを解放し、理論値の重ね表示と ±2σ の帯を最初から ON にします。
- 主張チェックの「先生用：解説をすべて表示」で全解説を一覧できます。
- 予想・理由・主張チェックの回答は、その端末のブラウザ（localStorage）にだけ保存されます。実験結果はページを開き直すと新しくなります。
- 乱数はブラウザの暗号学的乱数（`crypto.getRandomValues`）を使い、表／裏と1〜6の目を毎回独立に等確率で生成しています。

# 冷蔵庫エージェント・シミュレーション

家庭の食品ロス（食べ残し・直接廃棄・過剰除去）が、ふだんの行動だけからどう生まれるかを体験する
エージェントベースモデル（ABM）の教材アプリ。中学生から大学生・一般向け。授業・展示用。

- **理論**: エージェントベースモデル（買い物頻度・献立計画・見えない奥の食材）
- **パラメータ**: 買い物頻度、まとめ買い率、冷蔵庫の可視性、家族人数（くわしい設定で献立計画・過剰除去率も）
- **気づき**: 日本の家庭ロスの主因（食べ残し・直接廃棄・過剰除去）が行動から再現される
- **関連目標**: SDG 12.3

## 使い方

`refrigerator/index.html` をブラウザで開くだけで動きます（パソコン・スマホ対応）。
サーバー・ビルド・外部ライブラリは不要です。フォントは Google Fonts から読み込みますが、
オフラインでも端末のフォントで表示され、計算やアニメーションはそのまま動きます。
図とアニメーションはすべて Canvas でプログラム描画しています（写真・素材は未使用）。

## 内容

| タブ | 内容 |
|---|---|
| シミュレーション | 1つの家庭を 60 日動かす。冷蔵庫の中身のアニメーション、毎日の出来事ログ、1人1日あたりのロス（全国平均 約 50 g と比較）、内訳のドーナツ（全国の内訳と並べて比較）、日別の積み上げグラフ |
| 実験 | 1つのつまみだけ動かし、150 家庭 × 60 日の平均を棒グラフと表で比較。読み取りの文を自動生成 |
| しくみ | 1日のくり返し（買う→しまう→作る→食べる→残す・捨てる→1日たつ）、式、パラメータの意味、食材一覧、仮定 |
| データ | 国の推計（2024 年度：461 万トン、家庭系 224 万トン、内訳 96／93／35 万トン）、2030 年目標、消費者調査、UNEP、京都市の組成調査、農水省の世帯調査、参考文献 |
| 考える | 中学生向け・発展の問い、SDG 12.3 と日本、モデルの限界、発展課題 |

## モデルの概要

- 1家庭 = 1エージェント。毎日「買う → しまう → 作る → 食べる → 残す・捨てる → 1日たつ」を実行。
- 買う量 = max(0, 家族人数 × 500 g × 買い物間隔 − 把握している在庫) × (1 + まとめ買い率)。
- 新しい食材は手前へ。手前（8 か所）がいっぱいなら古い物が奥へ押しやられ、「奥行き < 可視性」のときだけ目に入る。
- 作る量 = 想定人数 × 500 g × (1 + ε)、ε ～ N(0, 12%)（献立計画の日は 6%）。家族 1 人につき 8%／日で不在。
- 食べ残し = 作って食べなかった分（保存しても 2 日で期限切れになった分を含む）、直接廃棄 = 残り日数 0 の食材、過剰除去 = 使った野菜 × 過剰除去率。
- 定数は、既定値（3 日に 1 回・まとめ買い 20%・可視性 60%・3 人・計画 30%）で 1人1日 約 50〜60 g、
  内訳が全国（42：43：16）に近い形になるよう調整した仮定値。
